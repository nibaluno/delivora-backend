# Delivora Backend

REST API для сервиса доставки еды. Бэкенд реализует регистрацию и авторизацию пользователей, управление ресторанами и меню, корзину, оформление заказов и административные операции для владельцев ресторанов.

## Стек технологий

| Категория | Технологии |
|-----------|------------|
| Язык | Java 17 |
| Фреймворк | Spring Boot 3.4 |
| Безопасность | Spring Security, JWT |
| База данных | Spring Data JPA, H2 |
| Документация API | SpringDoc OpenAPI (Swagger UI) |
| Утилиты | Lombok, MapStruct |
| Сборка | Gradle |

## Основной функционал

- **Аутентификация** — регистрация и вход по JWT-токену
- **Рестораны** — поиск, просмотр, добавление в избранное
- **Меню** — категории блюд, поиск еды, фильтрация (вегетарианское, сезонное и т.д.)
- **Корзина** — просмотр, добавление, изменение количества, удаление позиций, очистка
- **Заказы** — оформление заказа и история заказов пользователя
- **Админ-панель** — управление ресторанами, блюдами, ингредиентами и заказами
- **Роли** — `ROLE_CUSTOMER`, `ROLE_RESTAURANT_OWNER`, `ROLE_ADMIN`

## Архитектура

Проект построен по классической многослойной архитектуре Spring:

```
src/main/java/org/example/lr7/
├── config/       # Security, JWT, CORS
├── controller/   # REST-контроллеры
├── service/      # Бизнес-логика
├── repository/   # Spring Data JPA
├── model/        # Entity и enums
├── dto/          # Data Transfer Objects
├── request/      # DTO входящих запросов
└── response/     # DTO ответов API
```

## API

| Группа | Базовый путь | Описание |
|--------|--------------|----------|
| Auth | `/auth/**` | Регистрация и вход (публичный доступ) |
| Рестораны | `/api/reataurans` | Поиск и просмотр ресторанов |
| Еда | `/api/food` | Поиск и меню ресторана |
| Корзина | `/api/cart`, `/api/cart-item/**` | Просмотр и управление корзиной |
| Заказы | `/api/oder` | Создание и история заказов |
| Пользователи | `/api/users` | Профиль пользователя |
| Админ | `/api/admin/**` | Управление ресторанами, едой, ингредиентами, заказами |

**Корзина:**

| Метод | Путь | Описание |
|-------|------|----------|
| GET | `/api/cart` | Получить корзину текущего пользователя |
| PUT | `/api/cart/add` | Добавить блюдо в корзину |
| PUT | `/api/cart-item/update` | Изменить количество позиции |
| DELETE | `/api/cart-item/{id}/remove` | Удалить позицию из корзины |
| PUT | `/api/cart/clear` | Очистить корзину |

Защищённые эндпоинты требуют заголовок:

```
Authorization: <JWT-токен>
```

Полная интерактивная документация доступна после запуска приложения:

- Swagger UI: [http://localhost:8080/swagger-ui.html](http://localhost:8080/swagger-ui.html)
- OpenAPI JSON: [http://localhost:8080/v3/api-docs](http://localhost:8080/v3/api-docs)

## Быстрый старт

### Требования

- JDK 17+
- Git

### Запуск

```bash
git clone <repository-url>
cd delivora-backend
./gradlew bootRun
```

Приложение стартует на `http://localhost:8080`.

### Сборка и тесты

```bash
./gradlew build
./gradlew test
```

## Безопасность

- Stateless-сессии (JWT)
- BCrypt-хеширование паролей
- Ролевая модель доступа для административных маршрутов
- CORS настроен для локального фронтенда (`localhost:3000`, `localhost:8080`)
